
# Download Benchmark

Консольная утилита на Node.js для измерения средней
скорости скачивания данных по HTTP/HTTPS.

## Возможности

- Принимает URL из командной строки.
- Выполняет 10 последовательных HTTP-запросов.
- Дожидается полной загрузки каждого ответа.
- Измеряет время каждого запроса.
- Рассчитывает среднее время и общий объём данных.
- Выводит среднюю скорость в МБ/с и Мбит/с.
- Проверяет URL и обрабатывает ошибки запросов.

## Требования

- Node.js версии 18 или новее.
- Доступ к интернету.

Сторонние библиотеки не используются.

## Запуск

Откройте терминал в папке проекта:

```bash
node download.mjs https://example.com
```

Пример с тестовым файлом размером 1 МБ:

```bash
node download.mjs 'https://speed.cloudflare.com/__down?bytes=1000000'
```

## Расчёты

Среднее время запроса:

averageTime = totalTime / 10

Общая скорость скачивания:

speedMB = (totalBytes / (totalTime / 1000)) / 1000000

Скорость в мегабитах в секунду:

speedMbps = speedMB * 8

## Единицы измерения

- Время: миллисекунды (мс).
- Объём: байты.
- 1 секунда = 1000 миллисекунд.
- 1 МБ = 1 000 000 байт.
- 1 Мбит = 1 000 000 бит.
- 1 байт = 8 бит.

## Особенности измерения

Запросы выполняются последовательно.

Время включает ожидание HTTP-ответа и полное
чтение его содержимого.

Размер определяется по полученному ArrayBuffer.
При HTTP-сжатии он может отличаться от объёма
данных, переданных непосредственно по сети.

Программа измеряет скорость загрузки с конкретного
сервера, а не максимальную скорость интернет-канала.

При ошибке выполнение останавливается.
